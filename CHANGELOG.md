# Changelog

Todas los cambioa notables de este proyecto serán documentadas en este archivo.

## [v1.0] - 2026-05-03
### Añadido
- Creación de infraestructura básica S3 usando Terraform.
- Configuración de LocalStack mediante Docker Compose.
- Estructura de módulos para la reutilización del código (`modules/mi-recurso`).
- Implementación de flujos CI/CD con GitHub Actions (`validate.yml` y `deploy.yml`).
